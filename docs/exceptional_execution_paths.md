# Исключительные пути исполнения

Для сайта активных EXC-ID нет. Повторных запросов, запасных движков раскладки, внешних переводчиков и серверных API нет.

`i18n.js` выбирает поддерживаемый язык из `Accept-Language`, переданного Nginx через `browser-language.js`. Параметр `?lang=es|ru|en` задаёт явный выбор. Испанский для пустого, неизвестного или неподходящего заголовка — прямое требование владельца от 15.10.2026, а не обработка ошибки. При запуске без настройки Nginx статический `browser-language.js` задаёт отдельный локальный режим: языки берутся из `navigator.languages`.

Compose и systemd не перезапускают упавший контейнер: restart=no; unit запускает подготовленный image при загрузке без build/pull. Общий Caddy и его автоматическое получение/продление сертификатов относятся к политике хоста home_infra; HTTPS с автопродлением прямо поручен владельцем 15.10.2026. Приложение не добавляет сетевые повторы или запасной issuer.

Ошибки построения графа по-прежнему показываются в `ui-status`; граф очищается без повторов и смены движка. Архивные нормы сохраняют исходные байты и проверяются упаковщиками по SHA-256.

`analytics.js` подключает предоставленный владельцем Google tag `G-ZBZX7NP7HV` по прямому поручению от 15.10.2026. Это основной путь аналитики на HTTP(S)-сайте; file:// и loopback preview не подключают tag. Приложение не добавляет повторов или запасных провайдеров к внешнему Google tag. Проверка `tests/analytics.browser.cjs` перехватывает внешнюю загрузку и не отправляет тестовые посещения в Google.
